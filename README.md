# 01-news-scraper

A Python script that pulls news headlines from a website, cleans them, and prints the results.

**Status:** 🚧 In progress

## What it does
1. Fetches a news page
2. Extracts the headlines
3. Cleans them (removes extra spaces, duplicates and empty lines)
4. Prints the clean list

## Tech
- Python 3
- requests
- BeautifulSoup

## How to run
1. Clone this repo
2. Install the packages: `pip install requests beautifulsoup4`
3. Run: `python scraper.py`
